# 🛡️ Site de Segurança no Trabalho

Um portal completo e interativo dedicado à educação e promoção da segurança ocupacional.

## 📋 Características

- ✅ **Design Responsivo** - Funciona perfeitamente em desktop, tablet e celular
- ✅ **10 Dicas de Segurança** - Orientações práticas de segurança
- ✅ **Guia de EPI's** - Equipamentos de Proteção Individual detalhados
- ✅ **Legislação** - Normas e regulamentações de segurança
- ✅ **Formulário de Contato** - Integrado e funcional
- ✅ **Animações Suaves** - Efeitos visuais e transições elegantes
- ✅ **Navegação Intuitiva** - Menu de fácil acesso com links diretos

## 🚀 Como Usar

### Opção 1: Abrir Localmente
1. Clone o repositório
2. Abra o arquivo `index.html` em seu navegador
3. Pronto! O site está funcionando

### Opção 2: GitHub Pages (Recomendado)
1. Vá até as configurações do repositório
2. Em "Pages", selecione a branch `main`
3. Seu site estará disponível em: `https://seu-usuario.github.io/seguranca-trabalho`

## 📁 Estrutura de Arquivos

```
seguranca-trabalho/
├── index.html          # Página principal (HTML)
├── style.css           # Estilos (CSS)
├── script.js           # Funcionalidades (JavaScript)
└── README.md           # Este arquivo
```

## 🎨 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilos modernos com Grid e Flexbox
- **JavaScript Vanilla** - Funcionalidades interativas
- **Imagens** - URLs de sites gratuitos (Unsplash)

## 📸 Seções do Site

1. **Header** - Navegação sticky e logo
2. **Hero Section** - Banner de boas-vindas com CTA
3. **Dicas de Segurança** - 6 dicas essenciais em cards
4. **Equipamentos de Proteção** - Gallery de EPI's
5. **Legislação** - Normas regulamentadoras
6. **Formulário de Contato** - Sistema de contato funcional
7. **Footer** - Informações e créditos

## 🎯 Funcionalidades JavaScript

- ✅ Menu responsivo (hamburger)
- ✅ Scroll suave entre seções
- ✅ Validação de formulário
- ✅ Animações ao scroll
- ✅ Feedback de envio de formulário
- ✅ Navegação ativa
